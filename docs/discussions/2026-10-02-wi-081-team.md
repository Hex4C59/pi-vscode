## Scope and contract

Copy one nonempty, complete, safely projected assistant Markdown body from the current conversation, preserving whitespace and fences. Thinking, tools, metadata and rejected/hidden content are excluded. Empty, streaming, interrupted, failed, incomplete or truncated bodies have no reply-copy action. Existing code-block copy retains its semantics. Browser clipboard is the effect boundary; no host clipboard capability, raw buffer, persistence or new history reads.

Baseline ChatLine lacked per-message completion/fullness facts. Global chatBusy cannot establish eligibility. A owns the approved optional literal bodyCopyEligible flag, public DTOs/parser/contract; C owns conversation UI/copy translations/tests and the agreed host/adapter eligibility hunks. Missing eligibility means unavailable. Historical previews remain excluded; no full-text preview is fetched for copying.

Final producer rule: assistant message_end with stopReason equal to stop, no abort in flight, nonblank text-block body, unchanged by existing display redaction, and no 65,536-unit projection truncation. Adapter translates the fact; host suppresses it during Stop, transfers it to the row and removes it on a new delta. Renderer consumes only validated projection. Other stop reasons or absent evidence fail closed.

## Failure modes before implementation

Idle mistaken for completion; stopped/error/length/tool-use final treated as complete; capped or rejected text copied; thinking/tool input leaked through DOM extraction; fences/whitespace lost; user/history rows gain copy; old result overwrites changed reply; timeout fabricates success; repeated clicks start unbounded writes; unmount leaks timers; language change loses draft/focus; narrow feedback hides action; native denial reported as success.
