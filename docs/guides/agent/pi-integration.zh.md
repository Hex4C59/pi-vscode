## 何时加载与证据来源

涉及运行时启动、SDK/RPC 命令或事件、会话操作、资源加载、权限及上游依赖升级时加载。实现前阅读已批准架构／ADR、当前 WI、实际 gate ID、依赖固定版本及该已安装版本的公开文档。本地上游源码可解释行为，但不授权依赖私有模块或未文档化的文件布局。

记录准确包版本、公开入口、相关文档与观察行为。区分文档保证、spike 观察和假设。API 无法支持需求时记录缺口并重新讨论方案，不静默自行实现上游子系统。

通用 Promise 处理、取消、资源清理和 Node 进程规范遵循下方链接的 TypeScript/Node 指南，不在此重复。

## 集成职责

- 按产品决策流程选择内嵌 SDK 或子进程 RPC，不顺手切换进程模型。特权宿主拥有工作区策略、凭证和运行时生命周期；适配器将上游结果／事件映射到已文档化的产品契约；UI 仅接收批准的展示数据。
- 不重写上游 agent 循环、provider 栈或压缩机制。产品编排须使用公开 SDK/RPC API。
- 创建、恢复、切换等支持的操作使用上游会话 API。除非 Accepted ADR 明确授权例外，不为产品功能读写上游会话文件。返回的标识／路径作为公开 API 的不透明输入，不据此解析存储格式。
- 凭证和特权能力不得进入 UI 消息。不将低信任 UI 提交的任意 SDK 调用、命令名、shell 字符串或文件路径直接转发，须通过经校验、范围明确的宿主操作。

## RPC 与事件契约

- 按固定版本协议要求实现传输分帧，处理每次读取的半帧／多帧和文本编码分片；明确畸形、超大或截断输入的处理。协议输出与诊断分开，不假定一次 stdout 数据块就是一条消息。
- 读取字段前校验消息结构。区分命令响应、主动事件及协议支持的运行时向客户端请求。以待处理请求 ID 和预期操作关联响应；定义未知 ID、不支持消息和协议版本的处理。
- 分别定义命令确认、操作完成和流结束。保留所需事件顺序，不假定一次逻辑操作仅有一个事件，也不把重复出现的事件直接视为重复数据。
- 根据公开 API 证据明确允许的并发操作和取消语义。状态变更命令超时后，未确认结果与重试安全性前不重试。响应丢失不证明操作失败。
- 扩展适配器或 UI 桥前，在产品 reference 契约记录 DTO、错误和所有权。按实际成熟度使用 Planned/Outline/Living；写出 schema 不代表集成已实现。

## 运行时与会话生命周期

- 按需求定义可观察的启动中、就绪、停止中和失败状态；进程创建不等于就绪。启动失败或进程丢失时，结束待处理调用、使运行时身份失效，并通过宿主呈现失败。
- 停止、重启或切换会话／工作区时，明确处理待完成命令、流输出和审批请求。结果关联运行时／会话身份，防止旧回调影响替代会话。
- 验证上游会话切换、资源重载和取消的具体含义。未经文档与观察，不假定会话切换会更改 cwd、重载所有资源或重置权限。独立执行产品已批准的权限重置策略。
- 遵循 TypeScript 清理规则；集成检查还须观察子进程关闭与资源释放。发送终止信号不证明进程退出，短生命周期探针不等于生产会话管理器。

## 信任与资源加载

- 区分宿主工作区资格、上游项目资源批准和逐工具授权。工作区受信任不代表全部批准项目扩展或工具；资源加载选择不等于 shell／文件系统权限。
- 启动前核查文档默认值及持久／全局配置。产品要求明确选择资源时，传入受支持的显式控制并验证优先级，不依赖交互提示或默认拒绝的假设。
- 启动和切换时分别核查相关资源类别：扩展／包、设置、skills／prompts、上下文及全局资源。未观察类别明确报告，不由一个标记推断所有资源。
- 拒绝项目资源不一定阻止上下文读取、全局资源或普通工具访问。准确描述已验证范围。客户端或离线开关本身都不构成操作系统沙箱。

## Spike、回归检查与升级

- 从能回答 WI 问题的最小公开 API 探针开始。使用临时工作区／配置 fixture 和受控资源，隔离凭证、用户状态与环境。生命周期探针不得顺带安装项目包、执行真实项目扩展或调用模型。
- 测试相关成功与失败路径：启动失败、畸形协议、进程丢失、取消、迟到事件、切换和清理。断言禁止的动作未发生，例如不合格工作区不启动运行时。区分 mock 测试与真实运行时证据。
- 记录命令、准确版本／配置、预期与实际结果及剩余限制。未独立观察的资源或网络边界如实说明。有用发现写入现有讨论／WI 记录；满足所需验证与维护者确认后才写 Accepted ADR、关闭实际产品 gate。
- 升级时审阅公开 API／协议变化，隔离重跑受影响的生命周期、信任和会话检查。按已批准流程更新包固定版本／锁文件及相关决策记录。生产构建不得依赖未声明的同级仓库链接。

## 维护

集成交接时，将可复用协议或生命周期发现提炼到对应规则、链接证据并同步译文。版本特有事实与产品选择放在产品章节，与通用规则和历史观察分开。仅获授权时更新模板技术包。不因探针通过就将计划中的聊天、流式、会话管理或信任防护描述为已交付。

### 项目信任发现与剩余限制

[WI-003 记录](../../archive/2026-09-21-closed-wi-history.zh.md#wi-003)保存六组 `0.85.1` 场景、隔离方式、两次 resume 观察及未观察的 settings／themes／packages 限制。仅在分析相关信任或切换行为时加载；不可据其推断新版本验证或当前第三方扩展加载策略。WI-010 受控配置已禁用第三方扩展发现。

启动必须消费宿主当前明确的资源选择，重新核对资格／身份并使用公开控制；工作区资格、项目资源加载、工具审批各自独立。拒绝资源不等于排除 AGENTS.md 或全部用户上下文；离线开关不等于 OS 网络沙箱。当前批准的选择与重置要求属于 [PRD](../../product-requirements.zh.md)，完整验证状态属于 [Gate 表](../../reference/architecture-gates.zh.md)。

集成任务的完成记录须包含实际版本、运行命令、观察结果与剩余限制。包升级遵守 ADR 0001 的运行时探针及维护者复核要求，并重跑受影响信任／会话检查；保留历史版本结果，另记新证据。通用检查入口见[贡献指南](../../../CONTRIBUTING.zh.md)。
